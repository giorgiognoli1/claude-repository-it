Setup

Collega 33 connettori MCP a Claude

I connettori MCP pronti all'uso per marketing, sales, analytics, storage e social. Setup un-click e configurazione custom, con link per ogni connettore.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Cosa sono i connettori MCP|MCP (Model Context Protocol) è lo standard Anthropic-open-source che permette a Claude di chiamare strumenti esterni in modo strutturato. Un connettore MCP è un server che espone capability specifiche: leggere il filesystem, interrogare un database, postare su LinkedIn, fare scraping legale. Claude lo usa come se fosse una delle sue funzioni native.|Due modalità di setup|Modalità 1. One-click su claude.ai. Vai in Settings → Connectors e attivi quelli che ti servono. Modalità 2. Custom via configurazione JSON. Aggiungi il server MCP al tuo `claude_desktop_config.json` o `.mcp.json`. La seconda modalità ti permette di usare connettori non presenti nella lista ufficiale.|Le 5 famiglie|Famiglia 1. Produttività: Notion, Google Drive, Calendar, Gmail, Slack. Famiglia 2. Coding: GitHub, GitLab, Sentry, Linear, Jira. Famiglia 3. Marketing: HubSpot, Mailchimp, Buffer, Hootsuite. Famiglia 4. Analytics: Google Analytics, Mixpanel, Amplitude, PostHog. Famiglia 5. Storage e Database: Postgres, MySQL, Mongo, S3, Supabase.|I 33 connettori più utili|Notion, Google Drive, Calendar, Gmail, Slack, GitHub, GitLab, Linear, Jira, Sentry, HubSpot, Mailchimp, Buffer, Google Analytics, Mixpanel, Postgres, MySQL, Mongo, S3, Supabase, Stripe, Shopify, LinkedIn, X (Twitter), Reddit, Apify, browserless, filesystem, Figma, Canva, Airtable, Trello, Discord.|Configurazione JSON di esempio|```json
{
"mcpServers": {
"github": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"], "env": {"GITHUB_TOKEN": "ghp_xxxxxxxxxxxx"}},
"filesystem": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/Documents"]}
}
}
