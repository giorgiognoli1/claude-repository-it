Claude Base · Guida operativa

Smetti di caricare PDF su Claude: usa MarkItDown

Converti PDF, Word, PowerPoint e Excel in Markdown pulito con MarkItDown di Microsoft. Meno token, risposte più precise, setup Desktop in cinque minuti.

A cura di Giorgio Gnoli · 6 sezioni

Sintesi

Converti PDF, Word, PowerPoint e Excel in Markdown pulito con MarkItDown di Microsoft. Meno token, risposte più precise, setup Desktop in cinque minuti.

Perché caricare un PDF è un problema

Quando carichi un PDF direttamente su Claude, il tokenizer estrae il testo riga per riga. Il risultato è dannoso: più token, contesto sprecato, tabelle scomposte in righe senza relazioni. Spesso Claude legge male cifre, intestazioni, footer e layout a colonna.

La soluzione è convertire in Markdown prima di caricare. Ottieni testo semantico con titoli, elenchi e tabelle che Claude comprende al primo colpo. Il consumo di token cala tipicamente del 60-80%.

Setup MarkItDown in cinque minuti

  1. Installa Python 3.10+ e apri il terminale.
  2. Esegui pip install 'markitdown[all]'. La flag [all] abilita i plugin per PDF, DOCX, PPTX, XLSX, immagini, audio, HTML, CSV, JSON, XML, ZIP, EPub e URL YouTube.
  3. Converti un file: markitdown report.pdf > report.md.
  4. Apri il file Markdown e caricalo come testo in Claude.

Configurazione Desktop in un copia-incolla

Crea un piccolo script che riceve un file trascinato sopra e produce il Markdown accanto. Su Windows usa un .bat, su Mac e Linux uno .sh.

Windows

@echo off
python -m markitdown %1 > %~n1.md
start %~n1.md

Mac e Linux

#!/bin/bash
python3 -m markitdown "$1" > "${1%.*}.md"
open "${1%.*}.md"

Plugin supportati

MarkItDown supporta nativamente un’ampia gamma di formati. I più utili in pratica:

  • PDF — consigliato pdfminer come motore di estrazione.
  • DOCX, PPTX, XLSX — conversione completa di tabelle e stili.
  • JPG e PNG — con OCR testo-immagine integrato.
  • MP3 e WAV — trascrizione audio in testo.
  • HTML, CSV, JSON, XML, ZIP, EPub.
  • URL YouTube — estrae i sottotitoli come Markdown.

Per PDF complessi installa i plugin opzionali con pip install 'markitdown[pdf]' e 'markitdown[audio]'. La documentazione ufficiale è su github.com/microsoft/markitdown.

Quando convertire davvero

Converti sempre se il PDF contiene una di queste caratteristiche:

  • Tabelle numeriche o finanziarie.
  • Grafici, schemi, layout a più colonne.
  • Codice, formule o riferimenti incrociati.
  • Più di dieci pagine di testo strutturato.

Carica direttamente solo se il PDF è un testo narrativo breve, senza elementi strutturati, e ti serve solo un riassunto discorsivo.

Il risultato pratico

Claude userà meno token, capirà il documento meglio, e potrai fare domande puntuali su cifre e sezioni specifiche. Su documenti tecnici la qualità delle risposte migliora sensibilmente.
