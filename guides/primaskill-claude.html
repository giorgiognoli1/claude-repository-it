Claude Base

La tua prima Skill su Claude

Cos'è una Skill, dove salvarla, come testarla e come iterare in dieci minuti.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Cos'è una Skill|Una Skill è un file Markdown con istruzioni specialistiche che Claude legge quando riconosce un task compatibile. È il modo più semplice per 'insegnare' a Claude una procedura senza scrivere codice: qualità di output, formato di risposta, passi da seguire, errori da evitare.|Tipi di Skill|Skill globale: vive in `~/.claude/skills/` ed è disponibile in tutte le sessioni. Skill di progetto: vive in `.claude/skills/` nella cartella del progetto ed è disponibile solo lì. Skill di team: vive in un repo GitHub condiviso.|Anatomia di una Skill|```
---
name: nome-skill
description: una frase su quando attivarla
---

Istruzioni
