Claude Base

Roadmap Claude in cinque giorni

Piano operativo per essere produttivo con Claude in una settimana. Cosa fare ogni giorno.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Giorno 1. Setup base|Installa Claude Desktop. Configura la prima Skill di onboarding (chi sono, cosa faccio, preferenze). Esegui i primi 10 task banali per prendere confidenza con il prompt.|Giorno 2. Claude Code|Installa Claude Code. Configura repo `team-claude` con `CLAUDE.md`. Scrivi la prima Skill di progetto. Esegui una code review reale tramite Claude Code.|Giorno 3. Connettori MCP|Attiva i primi cinque connettori MCP: filesystem, GitHub, Calendar, Notion, Apify. Prova due task reali che richiedono dati esterni (es. riepilogo settimanale email + calendario).|Giorno 4. Architetture|Leggi Harness Engineering e Loop Engineering. Identifica un tuo task ripetitivo che può diventare un loop. Scrivi la prima bozza di agente con criterio di successo esplicito.|Giorno 5. Memoria e team|Implementa la memoria permanente con la strategia Obsidian + Git. Se lavori in team, configura la prima versione del repo `team-claude` e invita un collega per testare il loop build → push → invite → pull.|Cosa avrai|Dopo cinque giorni: setup completo, prima Skill installata, due connettori attivi, un loop agentico abbozzato, memoria permanente attiva. Non sarai esperto ma sarai produttivo.
