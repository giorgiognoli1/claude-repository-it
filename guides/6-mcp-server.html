Setup

Sei MCP server da configurare oggi

I sei server MCP che rendono Claude davvero operativo nel tuo lavoro quotidiano.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

I sei server|1. Filesystem. Accesso a cartelle locali. 2. GitHub. Repo, issue, PR, code review. 3. Apify. Scraping legale. 4. Notion. Documenti e database semantici. 5. Browserless. Browser headless per test e screenshot. 6. Postgres. Query al database in linguaggio naturale.|Perché questi sei|Coprono le sei capability fondamentali: leggere file locali, gestire codice, recuperare dati pubblici, gestire documentazione, navigare il web, interrogare dati strutturati. Insieme, rendono Claude operativo al 90% dei task quotidiani.|Setup comune|Configura ogni server in `claude_desktop_config.json` o `.mcp.json` con il pattern visto nella guida connettori MCP. Niente passi magici, solo JSON.|Ordine di installazione|Prima filesystem (subito utile). Poi GitHub se fai coding. Poi Notion se gestisci documentazione. Poi Apify se hai bisogno di dati pubblici. Poi Postgres se gestisci tabelle. Infine Browserless se devi testare UI.|Manutenzione|Tieni i token in `.env`. Aggiorna i server ogni 2-3 mesi (le versioni MCP evolvono). Verifica i log in `~/.claude/logs/mcp/` se qualcosa non funziona.
