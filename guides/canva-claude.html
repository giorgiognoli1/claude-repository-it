Integrare Canva con Claude via MCP

Da prompt a grafica pronta: pipeline Claude → Canva via MCP, con template brandizzati.

A cura di Giorgio Gnoli · 0 sezioni · 5 minuti di lettura

Scarica PDF

Sintesi

Da prompt a grafica pronta: pipeline Claude → Canva via MCP, con template brandizzati.

L'idea|Claude genera copy + brief grafico, Canva esegue con template brandizzato. Risultato: grafiche social pronte in dieci minuti senza toccare Canva manualmente.|Setup Canva|MCP|Configura `canva` MCP server in `~/.mcp.json`. Autentica via OAuth. Seleziona il team Canva con i template brand.|Il prompt generico|'Genera: copy LinkedIn (max 150 caratteri), brief grafico (soggetto, palette proposta, font), template Canva suggerito. Output: JSON con campi separati.'|Pipeline|Claude genera JSON → MCP chiama Canva API con template ID → riceve URL immagine → Claude scrive il post LinkedIn con allegato.|Esempio reale|Input: 'postauguri-per-cliente-X'. Output: copy 'Grazie a X per la fiducia di questi 5 anni!', brief 'soggetto: due mani che si stringono, palette: blu e oro, font: serif classico', template: 'greeting-card-v2'. Risultato: immagine pronta in Canva, pronta per il download.|Limiti|Canva MCP supporta template predefiniti, non creazione da zero. Per grafiche complesse serve plugin Adobe o Figma.|Costi|Canva Pro 12 euro/mese. MCP server gratuito.
