Claude Base

Smetti di caricare PDF su Claude: usa MarkItDown

Convertire PDF, Word, PowerPoint e Excel in Markdown pulito con MarkItDown di Microsoft. Setup Desktop in cinque minuti, meno token, risposte più precise.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Perché caricare un PDF è un problema|Quando carichi un PDF direttamente su Claude, il tokenizer estrae il testo riga per riga. Il risultato: più token, contesto sprecato, tabelle scomposte in righe senza relazioni. Spesso Claude legge male cifre, intestazioni, footer e layout. Soluzione: converti in Markdown prima, ottieni testo semantico con titoli, elenchi e tabelle che Claude comprende al primo colpo.|Setup MarkItDown in cinque minuti|Passo 1. Installa Python 3.10+ e apri il terminale. Passo 2. Esegui `pip install 'markitdown[all]'`. La flag `[all]` abilita i plugin per PDF, DOCX, PPTX, XLSX, immagini, audio, HTML, CSV, JSON, XML, ZIP, EPub e persino URL di YouTube. Passo 3. Converti un file: `markitdown report.pdf > report.md`. Passo 4. Apri il file Markdown e caricalo come testo in Claude.|Configurazione Desktop in un copia-incolla|Crea un file `markitdown.bat` (Windows) o `markitdown.sh` (Mac/Linux) che riceve un file trascinato sopra e produce il Markdown accanto:|Codice per Windows|`@echo off`
`python -m markitdown %1 > %~n1.md`
`start %~n1.md`|Codice per Mac/Linux|`#!/bin/bash`
`python3 -m markitdown "$1" > "${1%.*}.md"`
`open "${1%.*}.md"`|Tabella plugin supportati|MarkItDown supporta nativamente: PDF, DOCX, PPTX, XLSX, JPG/PNG (con OCR), MP3/WAV (trascrizione), HTML, CSV, JSON, XML, ZIP, EPub, URL di YouTube. Per i PDF consiglio pdfminer; per immagini e audio configura prima i plugin opzionali `markitdown[pdf]`, `markitdown[audio]`. La documentazione ufficiale è su github.com/microsoft/markitdown.|Quando convertire davvero|Converti sempre se il PDF contiene tabelle, grafici, schemi, codice, riferimenti incrociati o è più lungo di dieci pagine. Carica direttamente solo se il PDF è un testo narrativo breve senza elementi strutturati.|Risultato|Claude userà meno token, capirà il documento meglio e potrai fare domande puntuali su cifre e sezioni specifiche.|Disclaimer|MarkItDown è un progetto open source di Microsoft. Le istruzioni sono una rielaborazione della documentazione ufficiale, non una copia.
