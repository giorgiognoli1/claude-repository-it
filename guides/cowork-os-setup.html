Setup

Cowork OS: setup desktop passo per passo

Installazione e configurazione di Cowork OS su Mac, Linux e Windows. Permessi, cartelle locali, memoria.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Cos'è Cowork OS|Cowork OS è la modalità desktop di Claude che lavora direttamente sulle tue cartelle locali con gli stessi permessi tuoi. È il modo più potente per fare Claude lavorare sui tuoi file veri, senza upload ripetuti.|Requisiti|Mac: macOS 12+, Claude Desktop aggiornato. Linux: Ubuntu 20+ o equivalente, Python 3.10+. Windows: Windows 10+, PowerShell 7. Tutti: almeno 8 GB di RAM, 2 GB liberi su disco.|Installazione Mac|Scarica Claude Desktop da claude.ai. Apri System Settings → Privacy & Security → Accessibility e concedi accesso. Apri Cowork dal menu laterale.|Installazione Linux|`curl -L https://claude.ai/cowork/install.sh | bash`
`sudo systemctl enable --now claude-cowork`|Installazione Windows|Scarica l'installer. Apri PowerShell come amministratore e lancia `Enable-ClaudeCowork.ps1`. Configura cartelle condivise.|Cartelle locali|Per default Cowork accede a `~/Documents`, `~/Desktop`, `~/Downloads`. Puoi aggiungere cartelle custom in Settings → Cowork → Permissions.|Memoria locale|Cowork mantiene una memoria locale delle tue decisioni ricorrenti. Puoi esportarla e trasferirla a un altro device via `cowork export memory`.|Sicurezza|Non concedere accesso a cartelle con dati finanziari o sanitari senza un audit intermedio. Ogni tanto verifica la lista di file toccati in Settings → Activity.
