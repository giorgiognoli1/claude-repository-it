Prompt

Hacks per il limite di token

Tecniche per ridurre il consumo di token su input e output senza perdere qualità delle risposte.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Perché è importante|Ogni dollaro speso per token è un dollaro non speso per altro. Risparmiare il 30% di token senza calo di qualità significa ridurre i costi operativi di un terzo.|Hack input|1. Markdown invece di JSON quando possibile (più compatto). 2. Elimina boilerplate come 'Gentile AI, per favore'. 3. Usa istruzioni in elenco numerato, non discorsive. 4. Specifica la lunghezza output ('max 200 parole'). 5. Rimuovi esempi inutili dal system prompt. 6. Comprimi il contesto: invece di dieci documenti, riassumi i cinque più rilevanti.|Hack output|1. Chiedi risposte corte. 2. Chiedi formati strutturati: tabelle, JSON, elenchi. 3. Evita 'spiega in dettaglio': meglio 'rispondi in 5 punti'. 4. Usa `temperature` bassa per task ripetitivi. 5. Limita `max_tokens` se il caso d'uso lo permette.|Hack di sessione|1. `/compact` ogni 30 minuti. 2. `/clear` quando cambi task. 3. `cache_control` per prompt riutilizzati. 4. Sub-agent per task indipendenti, non una sessione unica lunghissima.|Misurazione|Stima token con `tiktoken` Python. Prima/dopo un hack, misura. Tiene solo ciò che funziona davvero.|Limiti|Non lesinare su qualità dove serve. Un report finanziario superficiale perché 'risparmiamo token' non è un risparmio, è un danno.
