Loop Engineering: guida completa

Dai prompt ai loop. Quattro ere dell'ingegneria dell'AI e le sei parti del loop agentico Anthropic per costruire agenti Claude robusti.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Dal prompt al loop|Un prompt è una domanda one-shot. Un loop è un ciclo che continua finché il task non è risolto. La differenza è enorme: con un prompt speri che il modello faccia tutto giusto al primo colpo, con un loop ti aspetti che il modello provi, verifichi, corregga e consegni un risultatoValidabile. La maggior parte del valore reale dell'AI si ottiene con i loop, non con i prompt puri.|Le quattro ere|Era 0. Chatbot (fino al 2022). Domande e risposte libere. Era 1. Prompt Engineering (2023). Istruzioni strutturate, esempi, formati di output. Era 2. Context Engineering (2024). RAG, tool use, memoria di sessione. Era 3. Loop Engineering (2025-). Agentic loops, sub-agent, valutazione automatica, osservabilità.|Le sei parti del loop agentico|1. Obiettivo. Una frase, un risultato, un criterio di successo. Senza obiettivo chiaro l'agente ristagna. 2. Strumenti. Le capability esterne che l'agente può chiamare: file system, codice, browser, API, MCP. 3. Criteri di successo. Come l'agente sa di aver finito: un file creato, un test passato, un valore numerico raggiunto. 4. Gestione errori. Cosa fare quando uno strumento fallisce: riprovare, cambiare approccio, chiedere aiuto umano. 5. Limiti di risorse. Tempo, token, chiamate strumenti, profondità di sub-agent. Senza limiti l'agente gira all'infinito e brucia budget. 6. Output finale. La struttura del risultato consegnato: file, dashboard, JSON, message.|Modello Anthropic|Claude Code implementa tutte e sei le parti: obiettivi chiari nel prompt, strumenti via MCP, successo tramite test eseguiti, error handling con retry intelligente, risorse limitate dal runtime, output come modifiche al filesystem. Studiando il comportamento di Claude Code impari il pattern.|Come scrivere il tuo primo loop|Parti da un task ripetitivo che fai a mano: rinominare file, estrarre dati, generare report. Definisci l'obiettivo, elenca gli strumenti, scrivi il criterio di successo, esegui una prima volta, aggiusta, ripeti.|Quando NON usare un loop|Se il task è creativo, one-shot, o richiede decisioni umane forti, un loop puro non basta. Meglio un prompt forte o una collaborazione agente-umano con punti di blocco espliciti.
