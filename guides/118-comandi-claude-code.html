Come è organizzato

Claude Code ha cinque famiglie di comandi: sessione, file system, git, skill e config. I 118 comandi totali coprono tutto il ciclo di vita di una sessione di lavoro.

Comandi di sessione

  • /help — mostra l’aiuto contestuale.
  • /clear — svuota il contesto.
  • /compact — riassume la conversazione per liberare token.
  • /resume — riprende una sessione precedente.
  • /exit — chiude la sessione.
  • /login — autentica.
  • /logout — disconnette.

Comandi file system

  • /read <file> — legge un file.
  • /write <file> <contenuto> — scrive un file.
  • /edit <file> <vecchio> <nuovo> — modifica un file.
  • /ls <cartella> — lista contenuti.
  • /find <pattern> — cerca ricorsivamente per nome.
  • /grep <pattern> — ricerca nei contenuti.

Comandi git

  • /git status — stato del repo.
  • /git diff — differenze non committate.
  • /git commit — committa le modifiche.
  • /git log — log delle commit.
  • /git branch — gestione branch.

Comandi skill

  • /skill list — lista delle Skill installate.
  • /skill enable <nome> — abilita una Skill.
  • /skill test <nome> — esegue test della Skill.
  • /skill create <nome> — wizard di creazione.

Comandi config

  • /model — cambia modello attivo.
  • /config — mostra la configurazione corrente.
  • /mcp add <server> — aggiunge un MCP server.
  • /hooks — gestione hook di automazione.

Come scegliere il comando giusto

Apri /help se non ricordi il comando. Se lavori su un file, usa /read e /edit. Se generi codice, preferisci le subroutine inline e usa i comandi slash per il meta-lavoro.

Performance

La maggior parte dei comandi è veloce. /compact e /resume sono i più costosi in token ma i più utili per sessioni lunghe. Usali ogni due-tre ore di lavoro continuato.
