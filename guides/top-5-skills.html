Sintesi

Una selezione di cinque Skill che uso ogni settimana. Copia, installa, personalizza.

Le cinque Skill

  1. Review PR — rivedi il diff, identifica cambio di scope, verifica test, scrivi review educata.
  2. Commit message — analizza il diff e scrivi un commit message semantico in italiano.
  3. Traduzione tecnica — traduci mantenendo la terminologia specifica con glossario allegato.
  4. Riepilogo esecutivo — estrai cinque punti, tre decisioni richieste, una sintesi.
  5. Analisi competitor — confronta due URL, estrai differenze di posizionamento, pricing, feature.

Installazione

Per ognuna: copia il testo, salvalo in ~/.claude/skills/<nome>/SKILL.md, riavvia Claude. Tempo medio: trenta secondi a Skill.

Personalizzazione

Dopo una settimana di uso, modifica la descrizione YAML e aggiungi due esempi di output ideale. La Skill migliora enormemente.

Quando rimuovere una Skill

Se non la usi per due settimane, rimuovila. Le Skill inattive intasano il contesto e confondono Claude quando decide se attivarle.
