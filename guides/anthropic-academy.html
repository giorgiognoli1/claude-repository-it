Claude Base

Anthropic Academy: come usarla bene

I corsi ufficiali Anthropic, dove trovarli, come sfruttarli al massimo senza perdere la motivazione.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Cos'è|Anthropic Academy è la piattaforma di corsi gratuiti di Anthropic su Claude 101, Claude API, Claude Code in Action e Prompt Engineering. I corsi sono video + esercizi pratici, ognuno della durata di 1-3 ore.|I corsi principali|Claude 101. Cos'è Claude, cosa fa bene, cosa fa male, prompt base. Building with the Claude API. Chiamate API, function calling, caching, gestione token. Claude Code in Action. Setup, repo CLAUDE.md, Skills, MCP, agenti. Prompt Engineering. Patterns, system prompt, esempi, few-shot, chain-of-thought.|Strategia di apprendimento|Una settimana per corso, fare gli esercizi, applicare a un progetto reale. Dopo il corso Claude 101 sei operativo. Dopo il corso API sei pronto a integrare. Dopo il corso Code sei pronto a sviluppare con harness. Dopo il corso Prompting sai ottimizzare a fondo.|Accounting del tempo|Investi 8-10 ore per corso. Rendimento atteso: abilità riutilizzabile per anni. ROI estremamente alto.|Dove trovare i corsi|anthropic.skilljar.com/claude-101, anthropic.skilljar.com/claude-api, anthropic.skilljar.com/claude-code, anthropic.skilljar.com/prompting. Salva i link nei preferiti e blocca due mezze giornate nel calendario.
