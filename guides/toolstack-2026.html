Sintesi

I dodici tool che ho sostituito nella mia catena operativa nel 2026. Categorie, alternative, motivi del cambio.

Search

Prima: Google con filtri manuali. Ora: Gemini con search grounding categorizzato. Motivo: risposta diretta invece di dieci link da visitare.

Spreadsheet

Prima: Excel con macro. Ora: Claude in Excel e GPT Sheets. Motivo: prompt naturali per analisi rapide e modellazione.

Generazione immagini

Prima: Midjourney con Photoshop. Ora: GPT Image 2 e Recraft. Motivo: editing più controllabile e text rendering pulito.

Design

Prima: Figma con plugin. Ora: Claude Design e Canva con MCP. Motivo: workflow prompt-driven end-to-end.

Scraping

Prima: script Python custom. Ora: Apify MCP. Motivo: zero manutenzione, legale, ripetibile.

Social scheduling

Prima: Buffer manuale. Ora: Buffer MCP con Claude. Motivo: copy e scheduling nello stesso flusso.

Email

Prima: Gmail manuale. Ora: Claude con Gmail MCP. Motivo: triage automatico, follow-up tracking, draft assistiti.

Coding

Prima: Copilot con ricerche Stack Overflow. Ora: Claude Code in repo locale. Motivo: agentic loop, code review integrato, MCP nativo.

Documenti

Prima: Word con revisioni manuali. Ora: Notion con Claude MCP. Motivo: struttura semantica, ricerca, modifiche prompt-driven.

Calendar

Prima: Google Calendar UI. Ora: Calendar MCP con Claude. Motivo: scheduling intelligente con lettura email automatica.

Database

Prima: SQL client con query manuali. Ora: Postgres MCP con Claude. Motivo: query in linguaggio naturale, analisi immediate.

Storage

Prima: Drive manuale. Ora: S3 MCP con Claude. Motivo: organizzazione automatica, tagging AI, ricerca semantica.
