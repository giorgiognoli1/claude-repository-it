Cowork OS: setup desktop passo per passo

Installazione e configurazione di Cowork OS su Mac, Linux e Windows. Permessi, cartelle locali, memoria.

A cura di Giorgio Gnoli · 8 sezioni

Sintesi

Installazione e configurazione di Cowork OS su Mac, Linux e Windows. Permessi, cartelle locali, memoria.

Cos’è Cowork OS

Cowork OS è la modalità desktop di Claude che lavora direttamente sulle tue cartelle locali con gli stessi permessi tuoi. È il modo più potente per fare Claude lavorare sui tuoi file veri, senza upload ripetuti e senza esportare manualmente i dati.

Requisiti

  • Mac — macOS 12+, Claude Desktop aggiornato.
  • Linux — Ubuntu 20+ o equivalente, Python 3.10+.
  • Windows — Windows 10+, PowerShell 7.
  • Tutti — almeno 8 GB di RAM, 2 GB liberi su disco.

Installazione Mac

  1. Scarica Claude Desktop da claude.ai.
  2. Apri System Settings → Privacy & Security → Accessibility e concedi accesso.
  3. Apri Cowork dal menu laterale di Claude Desktop.

Installazione Linux

curl -L https://claude.ai/cowork/install.sh | bash
sudo systemctl enable --now claude-cowork

Installazione Windows

  1. Scarica l’installer dal sito ufficiale.
  2. Apri PowerShell come amministratore.
  3. Lancia Enable-ClaudeCowork.ps1.
  4. Configura le cartelle condivise.

Cartelle locali

Per default Cowork accede a ~/Documents, ~/Desktop, ~/Downloads. Puoi aggiungere cartelle custom in Settings → Cowork → Permissions.

Memoria locale

Cowork mantiene una memoria locale delle tue decisioni ricorrenti. Puoi esportarla e trasferirla a un altro device con cowork export memory.

Sicurezza

Non concedere accesso a cartelle con dati finanziari o sanitari senza un audit intermedio. Ogni tanto verifica la lista di file toccati in Settings → Activity.
