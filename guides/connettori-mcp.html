Cosa sono i connettori MCP

MCP è lo standard open source di Anthropic che permette a Claude di chiamare strumenti esterni in modo strutturato. Un connettore MCP è un server che espone capability specifiche: leggere il filesystem, interrogare un database, postare su LinkedIn, fare scraping legale. Claude lo usa come se fosse una delle sue funzioni native.

Due modalità di setup

One-click

Vai in Settings → Connectors su claude.ai e attivi quelli che ti servono.

Custom via JSON

Aggiungi il server MCP al tuo claude_desktop_config.json o .mcp.json. Così puoi usare anche connettori non presenti nella lista ufficiale.

Le cinque famiglie

  • Produttività — Notion, Google Drive, Gmail, Slack.
  • Coding — GitHub, GitLab, Sentry, Linear, Jira.
  • Marketing — HubSpot, Mailchimp, Buffer, Hootsuite.
  • Analytics — Google Analytics, Mixpanel, Amplitude, PostHog.
  • Storage e Database — Postgres, Mongo, S3, Supabase.

Configurazione JSON di esempio

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {"GITHUB_TOKEN": "ghp_xxxxxxxxxxxx"}
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem","/Users/me/Documents"]
    }
  }
}

Best practice

  • Connetti solo i server che usi davvero — ogni connettore aggiunge token al contesto.
  • Tieni i token in variabili d’ambiente, mai nel JSON.
  • Documenta i connettori attivi in un README interno del team.
