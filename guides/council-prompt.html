Prompt · Guida operativa

Council di prompt: il prompt migliore vince

Tecnica per generare più varianti dello stesso prompt, valutarle, scegliere la migliore.

A cura di Giorgio Gnoli · 5 sezioni

Sintesi

Tecnica per generare più varianti dello stesso prompt, valutarle, scegliere la migliore.

L’idea

Un singolo prompt è una moneta lanciata in aria. Cinque varianti dello stesso prompt generano cinque risultati diversi. Chiedi a Claude di valutarli e scegliere il migliore.

Workflow

  1. Prepara un prompt base.
  2. Genera cinque varianti con prompt diversi.
  3. Fai valutare le cinque varianti da Claude secondo criteri espliciti.
  4. Scegli la migliore, documenta le motivazioni, salvala.

Criteri di valutazione

  • Chiarezza — il lettore capisce subito cosa fare.
  • Completezza — copre tutti i casi rilevanti.
  • Robustezza — funziona anche con input imperfetti.
  • Specificità — evita genericità.
  • Efficienza — usa il minor numero possibile di token.

Esempio pratico

Devi scrivere l’email di onboarding per nuovi clienti del tool. Scrivi cinque varianti di prompt: diretto, narrativo, formale, amichevole, ibrido. Fai valutare le cinque email risultanti secondo i cinque criteri.

Documenta la scelta

Ogni volta che scegli una variante, annota in un file prompt-history.md il prompt usato, i risultati, la scelta finale. Dopo sei mesi avrai una libreria di decisioni giustificate.
