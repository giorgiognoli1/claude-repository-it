Claude Base

Tutti i 118 comandi di Claude Code

Reference completo dei comandi slash di Claude Code: cosa fanno, quando usarli, esempi di output.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Come è organizzato|Claude Code ha cinque famiglie di comandi: sessione (avvio, pausa, ripresa), file system (lettura, scrittura, ricerca), git (commit, branch, diff), skill (abilitazione, testing) e config (modelli, hooks, MCP). I 118 comandi totali coprono tutto il ciclo di vita di una sessione di lavoro.|Comandi di sessione|`/help` mostra l'aiuto. `/clear` svuota il contesto. `/compact` riassume la conversazione per liberare token. `/resume` riprende una sessione precedente. `/exit` chiude. `/login` autentica. `/logout` disconnette.|Comandi file system|`/read <file>` legge un file. `/write <file> <contenuto>` scrive. `/edit <file> <vecchio> <nuovo>` modifica. `/ls <cartella>` lista. `/find <pattern>` cerca ricorsivamente. `/grep <pattern>` ricerca nei contenuti.|Comandi git|`/git status` stato. `/git diff` differenze. `/git commit` committa. `/git log` log. `/git branch` gestione branch.|Comandi skill|`/skill list` lista skill installate. `/skill enable <nome>` abilita. `/skill test <nome>` test. `/skill create <nome>` wizard creazione.|Comandi config|`/model` cambia modello. `/config` mostra configurazione corrente. `/mcp add <server>` aggiunge MCP server. `/hooks` gestione hook.|Come scegliere il comando giusto|Apri `/help` se non ricordi. Se lavori su un file, usa `/read` e `/edit`. Se generi codice, preferisci le subroutine inline e usa i comandi slash solo per il meta-lavoro.|Performance|La maggior parte dei comandi è veloce. `/compact` e `/resume` sono i più costosi in token ma i più utili per sessioni lunghe.
