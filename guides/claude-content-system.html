Claude Content System: un mese di contenuti in poche ore

Sistema di prompting per generare un mese di contenuti per più canali con voce coerente.

Scarica PDF

Sintesi

Sistema di prompting per generare un mese di contenuti per più canali con voce coerente.

L’idea

Un mese di contenuti si fa se hai una voce coerente, un calendario editoriale e prompt modulari. Claude Content System è esattamente questo: una libreria di prompt componibili che generano contenuti riutilizzabili con la stessa voce.

I moduli

  • Modulo Voce — file voice.md con tono, lunghezza media, lessico, esempi di apertura e chiusura.
  • Modulo Calendario — file calendar.md con i trenta argomenti del mese.
  • Modulo Prompt — tre template: LinkedIn post, carousel, email newsletter.

Il loop operativo

  1. Carica voice.md e l’argomento del giorno.
  2. Scegli il template.
  3. Genera prima bozza.
  4. Modifica manuale di due-tre parole per ancorare la voce.
  5. Salva in output/giorno-N-canale.md.
  6. Dopo sette giorni, rivedi cinque output migliori e affina voice.md.

Tempo reale

Circa tre ore per un mese di trenta contenuti su tre canali, inclusa la modifica manuale di personalizzazione. Rispetto ai cinque-otto giorni tradizionali è un risparmio dell’80%.
