Sub-agent in Claude Code: come e quando lanciarli

I sub-agent permettono di parallelizzare task indipendenti. Setup, limiti, esempi pratici.

A cura di Giorgio Gnoli · 5 sezioni

Sintesi

I sub-agent permettono di parallelizzare task indipendenti. Setup, limiti, esempi pratici.

Cos’è un sub-agent

Un sub-agent è una sessione Claude autonoma lanciata dal tuo agente principale per eseguire un task isolato. Ogni sub-agent ha il suo contesto, i suoi strumenti e il suo criterio di successo.

Quando lanciare un sub-agent

  • Task indipendenti che possono girare in parallelo.
  • Ricerche lunghe che sporcano il contesto principale.
  • Verifiche di qualità o test automatici.
  • Generazione di artefatti collateral al task principale.

Configurazione

In Claude Code i sub-agent si definiscono nel file CLAUDE.md del progetto. Specifica nome, strumenti, modello e criteri di successo.

Limiti pratici

Non lanciare un sub-agent per task semplici che puoi fare in linea. L’overhead di setup supera il beneficio. I sub-agent sono efficaci quando il task dura almeno qualche minuto.

Esempio end-to-end

Task: rivedere un PR di mille righe. L’agente principale lancia due sub-agent: uno analizza la logica, l’altro verifica i test. Poi integra i risultati e produce il commento di review.
