Harness Engineering, spiegato bene

Le tre ere dell'ingneria dell'AI e le cinque parti che trasformano un chatbot in un lavoratore: prompt, contesto, strumenti, loop di controllo, osservabilità.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

Cos'è un harness|Un harness è l'insieme di tutte le componenti software che stanno intorno a un modello per farlo lavorare su un task reale. Senza harness Claude è un chatbot brillante, con il harness diventa un lavoratore. Il termine è diventato di uso comune nel 2025: Anthropic, OpenAI e molti progetti open source pubblicano i propri harness come riferimento.|Le tre ere dell'ingegneria AI|Era 1. Prompt Engineering (2022-2023). I modelli sono deboli, conta la forma del prompt. Era 2. Context Engineering (2024). Modelli più capaci, il collo di bottiglia è la qualità del contesto: documenti, memoria, strumenti. Era 3. Harness Engineering (2025-). Modelli potenti, il collo di bottiglia è l'architettura del sistema che li guida.|Le cinque parti|1. Modello. La scelta del modello: Claude Sonnet per task complessi, Haiku per task ripetitivi, Opus per ragionamento profondo. 2. Contesto. Cosa entra nella finestra di input: istruzioni di sistema, esempi, documenti, memoria, strumenti disponibili. 3. Strumenti. Le capability esterne: function calling, MCP, esecuzione di codice, file system, browser. 4. Loop di controllo. La pipeline di esecuzione: ricevi task → pianifica → esegui → verifica → correggi → riporta. 5. Osservabilità. Log strutturati, metriche di successo, tracciamento delle decisioni. Senza osservabilità non sai se l'agente sta peggiorando.|Come si progetta un harness|Claude Code è un esempio di harness Anthropic-ready. Cowork OS è un harness desktop-oriented. La tua Skill è un mini-harness verticale. Combinando Skills più grandi, MCP server e memoria ottieni un harness su misura per il tuo dominio.|Regola d'oro|Un harness è un prodotto software: va versionato, testato, distribuito. Non credere di averlo finito dopo la prima scrittura: il miglioramento è continuo.
