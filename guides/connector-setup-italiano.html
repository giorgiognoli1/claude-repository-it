Setup MCP in italiano: guida pratica

Procedura passo per passo per configurare il tuo primo connettore MCP con un esempio italiano end-to-end.

A cura di Giorgio Gnoli · 5 sezioni

Sintesi

Procedura passo per passo per configurare il tuo primo connettore MCP con un esempio italiano end-to-end.

Prerequisiti

  • Claude Desktop aggiornato all’ultima versione.
  • Node.js 18+ installato sul sistema.
  • Un account con credenziali API del servizio che vuoi connettere.

Il file di configurazione

Su macOS il file è ~/Library/Application Support/Claude/claude_desktop_config.json. Su Windows è %APPDATA%\Claude\claude_desktop_config.json. Su Linux è ~/.config/Claude/claude_desktop_config.json.

Esempio completo

Per connettere Notion:

{
  "mcpServers": {
    "notion": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-notion"],
      "env": {"NOTION_TOKEN": "secret_xxxxxxxxxxxx"}
    }
  }
}

Riavvio e test

  1. Salva il file JSON.
  2. Riavvia Claude Desktop.
  3. Apri una nuova chat.
  4. Chiedi: quali pagine ho su Notion? Se Claude risponde, il connettore funziona.

Debug comune

  • Token non valido — ricontrolla la variabile d’ambiente.
  • Porta occupata — chiudi altri processi che usano lo stesso tool.
  • Errore di permessi — verifica ACL del servizio esterno.
