Le 3 modalità di Claude Code

Quando usare la chat, quando entrare in Code, quando attivare la modalità agente. Differenze, limiti, esempi.

A cura di Giorgio Gnoli · 5 sezioni

Scarica PDF

Sintesi

Quando usare la chat, quando entrare in Code, quando attivare la modalità agente. Differenze, limiti, esempi.

Modalità 1 — Chat pura

Interfaccia testuale, nessun tool accessibile. Ideale per brainstorming, scrittura creativa, chat di consulenza, risposta a domande puntuali.

  • Vantaggi — massima chiarezza, zero side-effect.
  • Limiti — niente file, niente codice, niente ricerche esterne.

Modalità 2 — Code con file system

Claude Code può leggere e scrivere file, eseguire comandi shell, fare git. Ideale per sviluppo, refactor, code review, documentazione.

  • Vantaggi — azioni reali sul codice.
  • Limiti — serve supervisione umana, può rompere cose.

Modalità 3 — Agente con loop e MCP

Claude gira in loop con obiettivo, strumenti MCP, criterio di successo, gestione errori. Lavora in autonomia finché non raggiunge il goal. Ideale per task ripetitivi e data pipeline.

  • Vantaggi — scalabile, automatizzabile.
  • Limiti — serve harness robusto, osservabilità, limiti di risorse.

Come scegliere

Parti sempre dalla chat pura per definire cosa vuoi. Passa in Code quando serve azione su file. Passa in agente solo se il task è ripetitivo, misurabile e ben definito. Non lanciare agenti su task vaghi o one-shot.

Esempio

  • Rivedi il PR numero 123 in modo educativo → Modalità Code.
  • Rivedi tutti i PR aperti e genera un report settimanale → Modalità agente.
  • Spiegami le differenze tra harness e loop → Chat pura.
