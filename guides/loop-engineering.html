Sintesi

Dai prompt ai loop. Quattro ere dell’ingegneria AI e le sei parti del loop agentico Anthropic per costruire agenti Claude robusti.

Dal prompt al loop

Un prompt è una domanda one-shot. Un loop è un ciclo che continua finché il task non è risolto. La differenza è enorme: con un prompt speri che il modello faccia tutto giusto al primo colpo. Con un loop ti aspetti che provi, verifichi, corregga e consegni un risultato validabile.

Le quattro ere

  • Chatbot (fino al 2022) — domande e risposte libere.
  • Prompt Engineering (2023) — istruzioni strutturate, esempi, formati di output.
  • Context Engineering (2024) — RAG, tool use, memoria di sessione.
  • Loop Engineering (2025-) — agentic loop, sub-agent, valutazione automatica, osservabilità.

Le sei parti del loop agentico

  1. Obiettivo — una frase, un risultato, un criterio di successo. Senza obiettivo chiaro l’agente ristagna.
  2. Strumenti — capability esterne che l’agente può chiamare: file system, codice, browser, API, MCP.
  3. Criteri di successo — come l’agente sa di aver finito: file creato, test passato, valore numerico raggiunto.
  4. Gestione errori — riprovare, cambiare approccio, chiedere aiuto umano.
  5. Limiti di risorse — tempo, token, chiamate strumenti, profondità di sub-agent. Senza limiti l’agente gira all’infinito.
  6. Output finale — struttura del risultato consegnato: file, dashboard, JSON, messaggio.

Il modello Anthropic

Claude Code implementa tutte e sei le parti: obiettivi chiari nel prompt, strumenti via MCP, successo tramite test eseguiti, error handling con retry intelligente, risorse limitate dal runtime, output come modifiche al filesystem. Studiando il comportamento di Claude Code impari il pattern.

Come scrivere il tuo primo loop

Parti da un task ripetitivo che fai a mano: rinominare file, estrarre dati, generare report. Definisci l’obiettivo, elenca gli strumenti, scrivi il criterio di successo, esegui una prima volta, aggiusta, ripeti.

Quando NON usare un loop

Se il task è creativo, one-shot o richiede decisioni umane forti, un loop puro non basta. Meglio un prompt forte o una collaborazione agente-umano con punti di blocco espliciti.
