Prompt · Guida operativa

Dieci agenti Claude per la finanza personale

Una libreria di dieci agenti specializzati per gestire le finanze personali con Claude e MCP.

A cura di Giorgio Gnoli · 5 sezioni

Sintesi

Una libreria di dieci agenti specializzati per gestire le finanze personali con Claude e MCP.

La libreria

Dieci agenti specializzati, ciascuno con un prompt dedicato, una Skill di attivazione e un criterio di successo. Coprono il ciclo completo: dal budgeting alla pianificazione pensionistica.

I dieci agenti

  1. Budget agent — categorizza le spese e segnala derive.
  2. Cashflow agent — proietta saldo tra sei mesi.
  3. Debito agent — calcola strategia di estinzione anticipata.
  4. Risparmio agent — suggerisce allocazione mensile.
  5. Investimento agent — propone ETF coerenti con il profilo.
  6. Tasse agent — evidenzia detrazioni non sfruttate.
  7. Stipendio agent — calcola netto, rate, tredicesima.
  8. Pensione agent — proietta TFR e contributi.
  9. Mutuo agent — confronta tassi, calcola rata, scenari TAEG.
  10. Report agent — genera report mensile PDF.

Setup condiviso

Tutti usano lo stesso MCP: il filesystem locale, un file finanze.xlsx e un Google Sheet condiviso via MCP. Il prompt di ogni agente fa riferimento al file.

Skill di attivazione

---
name: budget-agent
description: attiva quando l'utente chiede di categorizzare spese
oppure di analizzare il budget mensile
---

# Ruolo
Sei il budget agent. Ricevi il file finanze.xlsx aggiornato.
Per ogni mese: categorizza spese, evidenzia derive oltre il 10%,
suggerisci tagli non dolorosi. Output: tabella markdown + sintesi.

Governance

Anche se gli agenti sono potenti, le decisioni finanziarie finali restano sempre umane. Verifica sempre i dati, non fidarti ciecamente. Gli agenti sono assistenti, non consulenti finanziari.
