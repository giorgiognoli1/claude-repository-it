Sintesi

Cos’è una Skill, dove salvarla, come testarla e come iterarla in dieci minuti.

Cos’è una Skill

Una Skill è un file Markdown con istruzioni specialistiche che Claude legge quando riconosce un task compatibile. È il modo più semplice per insegnare a Claude una procedura senza scrivere codice: qualità di output, formato di risposta, passi da seguire, errori da evitare.

Tipi di Skill

  • Globale — vive in ~/.claude/skills/ ed è disponibile in tutte le sessioni.
  • Di progetto — vive in .claude/skills/ nella cartella del progetto, disponibile solo lì.
  • Di team — vive in un repo GitHub condiviso e si propaga a tutti i collaboratori.

Anatomia di una Skill

---
name: nome-skill
description: una frase su quando attivarla
---

# Istruzioni

Passi che Claude deve seguire quando questa Skill è attiva.

La tua prima Skill in dieci minuti

Scegli un task ripetitivo: rivedere un PR di GitHub. Crea il file ~/.claude/skills/review-pr/SKILL.md. Nello YAML dichiara nome e descrizione. Nel corpo scrivi le istruzioni operative.

  1. Leggi il diff.
  2. Identifica il cambio di scope.
  3. Verifica la presenza di test.
  4. Scrivi una review educata e orientata al miglioramento.

Salva. Apri una sessione Claude Code, digita rivedi questo PR: <url>. Claude riconosce la Skill e la applica.

Test e iterazione

  • Testa su cinque PR reali.
  • Se l’output è troppo lungo, aggiungi max 200 parole alla descrizione.
  • Se troppo generico, aggiungi due-tre esempi di output ideale.
  • Salva la nuova versione: le Skill migliorano per iterazione, non per riscrittura.
