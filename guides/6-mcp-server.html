Sintesi

Una selezione ragionata di sei MCP server che coprono i casi d’uso più comuni.

I sei server

  1. Filesystem — accesso controllato a cartelle locali.
  2. GitHub — lettura issue, PR, file di repo remoti.
  3. Notion — lettura e scrittura di pagine e database.
  4. Apify — orchestrazione di scraper pronti.
  5. Postgres — query SQL in linguaggio naturale.
  6. Calendar — gestione appuntamenti e lettura eventi.

Ordine di setup consigliato

  1. Filesystem — il più immediato, zero credenziali esterne.
  2. GitHub — essenziale per chi sviluppa.
  3. Notion — perfetto per knowledge worker.
  4. Apify — per task di ricerca e monitoraggio.
  5. Postgres — per chiunque abbia un database.
  6. Calendar — per scheduling intelligente.

Pattern di configurazione

Tutti i server MCP seguono lo stesso pattern nel JSON: command, args, env. La principale differenza è il nome del pacchetto npm e le variabili d’ambiente richieste.

Buone pratiche

  • Aggiungi un server alla volta e verificalo prima di passare al successivo.
  • Tieni i token in un password manager, non nel file JSON.
  • Documenta ogni server in un README del team con link e scopo.
