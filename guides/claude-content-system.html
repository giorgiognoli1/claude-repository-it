Prompt

Claude Content System: un mese di contenuti in poche ore

Sistema di prompting per generare un mese di contenuti per più canali con voce coerente.

A cura di Giorgio Gnoli · Guida operativa, licenza libera con attribuzione.

L'idea|Un mese di contenuti si fa se hai (1) una voce coerente, (2) un calendario editoriale, (3) prompt modulari. Claude Content System è esattamente questo: una libreria di prompt componibili che generano contenuti riutilizzabili con la stessa voce.|I moduli|Modulo Voce. File `voice.md` con tono, lunghezza media, lessico, esempi di apertura/chiusura. Modulo Calendario. File `calendar.md` con i 30 argomenti del mese. Modulo Prompt. Tre template: LinkedIn post, carousel, email newsletter.|Il loop|1. Carica `voice.md` e l'argomento del giorno. 2. Scegli il template. 3. Genera prima bozza. 4. Modifica manuale di 2-3 parole per ancorare la voce. 5. Salva in `output/giorno-N-canale.md`. 6. Dopo 7 giorni, rivedi 5 output migliori e affina `voice.md`.|Esempio di output LinkedIn|`5 cose che ho imparato gestendo 100 task con Claude.`

`1. La memoria permanente vale più di qualsiasi prompt perfetto.`
`... (continua) `

`Salva questo post e condividilo con chi gestisce task come te.`|Estensioni|Per X (Twitter) genera thread. Per Instagram genera carousel di 7 slide. Per email genera sequenza di 3 follow-up.|Tempo reale|Circa 3 ore per un mese di 30 contenuti su 3 canali, inclusa la modifica manuale di personalizzazione.
