Apify per Claude: scraping legale e ripetibile

Recuperare dati pubblici dal web dentro Claude tramite Apify MCP, in modo legale, etico, ripetibile.

A cura di Giorgio Gnoli · 7 sezioni

Scarica PDF

Sintesi

Recuperare dati pubblici dal web dentro Claude tramite Apify MCP, in modo legale, etico, ripetibile.

Cos’è Apify

Apify è una piattaforma di web scraping con migliaia di Actor pronti, mini-script specializzati. La versione cloud è gestita, legale (rispetta robots.txt), a norma GDPR.

Perché integrarlo con Claude

Claude può orchestrare Actor Apify: chiedere titoli di prodotto Amazon, prezzi su eBay, post LinkedIn di un profilo, recensioni di un ristorante. Il workflow diventa un agente ripetibile.

Setup

  1. Crea un account su apify.com.
  2. Ottieni un API token dal dashboard.
  3. Aggiungi Apify MCP al claude_desktop_config.json.
  4. Riavvia Claude Desktop.

File di configurazione

{
  "mcpServers": {
    "apify": {
      "command": "npx",
      "args": ["-y", "@apify/mcp-server"],
      "env": {"APIFY_TOKEN": "tuotoken"}
    }
  }
}

Esempio di uso

Claude prompt: Estrai le prime dieci recensioni di questo ristorante su Google Maps e riassumi il sentiment. Claude lancia l’Actor google-maps-scraper, riceve JSON, lo riassume in linguaggio naturale.

Limiti etici

  • Non scrapeare siti con login obbligatorio o che vietano lo scraping nei ToS.
  • Non pubblicare dati personali.
  • Rispetta i rate limit.

Costi

Apify ha un free tier di cinque dollari al mese. Per uso più intensivo esistono piani da 49 dollari al mese con Actor illimitati.
